# 口算小搭档：基础开发项目

## 导入与运行

1. 打开微信开发者工具，选择“小程序”里的“导入项目”。
2. 目录选择本文件所在的 `miniapp` 文件夹，而不是外层仓库。
3. AppID 已写入 `project.config.json`：`wxeeac1150bc72adb2`。
4. 导入后点击“编译”。以该小程序管理员或已添加的开发者身份登录。
5. 当前使用微信原生 JavaScript、WXML、WXSS，不需要安装第三方依赖、构建 npm 或创建云环境。

## 已有与待做

已有：六个注册页面、首页导航、普通／限时设置切换、10—50 整数题量验证、设置到答题占位页的参数传递，以及应用头像与基础配色。

第一轮预览配置固定为 20 以内加减法，默认 30 题，时长候选 60／120／180 秒、默认 120 秒。这是开发起点，不是最终功能范围或经过核实的年级教学规则。需求仍以外层 docs 中的立项与变更记录为准。

未实现：实际出题与作答、计时、批改、结果、错题、存储、房间、可信身份、云函数、比赛与同步。占位页明确显示尚未开放；没有伪造房间、成绩或练习历史。结果页已注册，但在真实提交流程接入前没有业务入口。

这是一份开发基础项目，不能视为已完成课程要求或可发布版本。AppID 的有效性和开发权限需在开发者工具中确认；尚未确认服务类目、审核和云资源条件。

## 第一轮手工检查

- 编译后能显示“口算小搭档”首页和头像。
- 普通入口默认不限时；限时入口默认 120 秒，能切换 60／180 秒。
- 空题量、9、51 等无效输入不能进入答题页；10、30、50 能进入，摘要与设置一致。
- 答题页明确显示正在准备，不生成题目、不启动计时。
- 房间及记录入口能打开，说明功能尚未开放。
- 开发者工具控制台没有编译错误。每位成员记录自己的工具版本、手机与检查结果，未执行的检查不要标为通过。
