# 口算小搭档：基础开发项目

## 导入与运行

1. 打开微信开发者工具，选择“小程序”里的“导入项目”。
2. 目录选择本文件所在的 `miniapp` 文件夹，而不是外层仓库。
3. AppID 已写入 `project.config.json`：`wxeeac1150bc72adb2`。
4. 导入后点击“编译”。以该小程序管理员或已添加的开发者身份登录。
5. 当前使用微信原生 JavaScript、WXML、WXSS，不需要安装第三方依赖、构建 npm 或创建云环境。

## 已有与待做

已有：六个注册页面、首页导航、普通／限时设置切换、一至三年级的题型选择、10—50 整数题量验证、设置到答题页的参数传递与摘要展示，以及应用头像与基础配色。

**当前可演示**：整数四则已经能真实出题、作答和批改。覆盖 10 个预设：
一年级 20 以内、二年级 100 以内、三年级 1000 以内的加减法，以及表内乘除、两位数乘一位数、
两位数除以一位数（整除）。答题页支持逐题输入、返回修改、空白记未答、`0` 作为有效答案、
交卷批改、限时倒计时与到时自动交卷；结果通过 eventChannel 和 `pendingPracticeResult` 交给结果页。
剩余 3 个题型（混合运算、小数、分数）会显示「该题型尚未开放」，不会静默降级成别的题型。
表内乘法只有 45 种算式，选 50 题时会提示「该范围内只有 45 种算式，请把题量调小」。

当前默认一年级、20以内加法、30题；普通练习不限时，限时练习默认120秒，可选60／120／180秒。二年级可选100以内加减法和表内乘除法；三年级可选基础四则、整数两步混合、一位小数加减及同分母分数加减。它们已由组长于 2026-10-27 确认纳入首版，来源与后续输入、精确判题、历史保存要求见[扩展题型与开赛规则确认](../docs/07_扩展题型与开赛规则确认.md)。设置预设不表示对应出题或判题已经实现，也不代表完整教材覆盖。

完整题型规则、参数约定及联调说明见外层 [年级题型设置交付说明](../docs/年级题型设置交付说明.md)，出题与判分的技术约定见[接口与判分说明](../docs/接口与判分说明.md)。

未实现：混合运算、小数、分数的生成与判题（下一阶段）、结果页展示、错题、记录存储、房间、可信身份、云函数部署、比赛与同步。结果页已注册，但在彭方鑫接入前没有业务展示。

这是一份开发基础项目，不能视为已完成课程要求或可发布版本。AppID 的有效性和开发权限需在开发者工具中确认；尚未确认服务类目、审核和云资源条件。

## 第一轮手工检查

- 编译后能显示“口算小搭档”首页和头像。
- 普通入口默认不限时；限时入口默认 120 秒，能切换 60／180 秒。
- 切换年级后题型与范围同步更新；题量、模式和时长保持原选择。
- 三年级可在“整数口算”和“小数与分数”两组之间选择，隐藏的题型不会继续生效。
- 空题量、9、51 等无效输入不能进入答题页；10、30、50 能进入。
- 选一年级加减法进入答题页：题干形如 `12 - 5 = ?`，页面上看不到答案；控制台有「出题来源：local」和 ruleId。
- 选二年级表内乘法：题干形如 `7 × 8 = ?`，答案范围 1—81；选表内除法：能整除、商 1—9。
- 选三年级两位数乘一位数、两位数除以一位数：乘数 1—9，除法必须整除。
- 表内乘法选 50 题：答题页提示「该范围内只有 45 种算式，请把题量调小」，不进入答题。
- 输入 `0` 能正常保存；清空算未答；上一题/下一题来回切换不丢已填答案。
- 留几题不填点交卷，提示还剩几道；确认后弹窗的对/错/未答数字与手算一致。
- 限时 60 秒：右上角倒计时，归零自动交卷，且只弹一次结果。
- 选三年级混合运算、小数或分数：答题页显示「该题型尚未开放」，不出现题目，也不把题型换成加法。
- 非法链接（如 `grade=1&ruleId=g3_fraction_same_den`）只显示「练习设置无效」，不展示有效配置。
- 返回练习设置保留原来的年级、题型、题量和时长。
- 房间及记录入口能打开，说明功能尚未开放。
- 开发者工具控制台没有编译错误。每位成员记录自己的工具版本、手机与检查结果，未执行的检查不要标为通过。

## 自动检查

在外层本地仓库目录运行：

```powershell
node --test tests/question.test.js          # 出题、判分、接口契约、云函数副本一致性
node --test tests/practice-settings.test.cjs # 设置页到答题页的参数往返（含 13 个题型）
```

出题与判分用例不依赖微信开发者工具（当前 48 项）。设置页的 39 项用例用于确认本轮改动没有破坏原有参数契约。
两者都不替代微信开发者工具和真机验证。

布局回归可运行 `node tests/settings-layout.browser.cjs`，需要本机 Chrome（可用 CHROME_PATH 指定路径）。
它检查 320／375／430 宽度下原生按钮默认尺寸是否导致重叠或越界；不替代真机复查。
