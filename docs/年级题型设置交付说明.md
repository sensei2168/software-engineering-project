# 年级题型设置交付说明

本次按用户确认的V2草图，实现一至三年级设置、三年级题型分组、规则样例、参数校验及下一页摘要。首页内容、全局样式、项目配置保持原样。实际出题、作答输入、计时、判题、房间和存储仍未实现。

2026-10-27，组长明确同意将混合运算、小数和分数纳入首版。需求来源 S10、影响编号和交接责任见[扩展确认记录](07_扩展题型与开赛规则确认.md)。年级标签仍是产品预设，教学适配依据待核对，不因采纳功能就认定教材核实完成。

## 页面行为

- 首次进入默认一年级、加法、30道；普通入口不限时，限时入口默认120秒。
- 年级和题型均单选。年级切换时优先保留同一种运算，并同步更新范围；新年级没有原题型时切回加法并提示。
- 三年级分“整数口算”“小数与分数”。切换分组选择该组第一种题型并提示；重复点击已选分组不改变当前题型。
- 切换年级、分组或模式时保留已输入题量和所选时长。题量仍为10—50整数，时长仍为60／120／180秒；普通模式不显示时长，不会启动计时。
- 题型按钮标明范围，样例随选择更新；分数样例以分子／分母上下排列展示。
- 下一页使用同一规则表展示年级、题型和范围。正常返回设置保留原页面；独立打开摘要时，返回会携带完整参数恢复设置。

## 题型与规则编号

规则表位置为 `miniapp/utils/practice-rules.js`。后续生成器应按 `ruleId` 选择规则，不能单凭年级或 `limit` 猜测。

| 年级 | ruleId | 设置名称 | 出题模块后续应遵守的范围 |
| --- | --- | --- | --- |
| 一 | g1_add_20 | 加法 | 两个0—20整数，和不超过20 |
| 一 | g1_subtract_20 | 减法 | 两个0—20整数，差非负 |
| 二 | g2_add_100 | 加法 | 两个0—100整数，和不超过100 |
| 二 | g2_subtract_100 | 减法 | 两个0—100整数，差非负 |
| 二 | g2_multiply_table | 表内乘法 | 两个乘数为1—9 |
| 二 | g2_divide_table | 表内除法 | 除数与商均为1—9，被除数为两者之积 |
| 三 | g3_add_1000 | 加法 | 两个0—1000整数，和不超过1000 |
| 三 | g3_subtract_1000 | 减法 | 两个0—1000整数，差非负 |
| 三 | g3_multiply_2by1 | 乘法 | 10—99乘1—9 |
| 三 | g3_divide_2by1 | 除法 | 两位数除以1—9，除数非零且整除 |
| 三 | g3_mixed_2step | 混合运算 | 三个整数、两个运算符，无括号；运算数、中间结果与最终结果为0—100；遵循运算顺序，除数非零且整除 |
| 三 | g3_decimal_1place | 小数加减 | 一位小数单步加／减，运算数与结果在0—10，结果非负 |
| 三 | g3_fraction_same_den | 分数加减 | 两个同分母真分数单步加／减，分母2—9，结果在0—1，不要求约分 |

小数加减、分数加减各自在一份练习中安排加法题和减法题，数量尽量均衡，奇数题量多一道加法。这是待出题模块落实的规则，不是本轮已实现的生成结果。

## 参数契约

设置到摘要仍通过页面URL传递，示例：

```json
{
  "grade": 3,
  "ruleId": "g3_fraction_same_den",
  "operation": "fraction_add_sub",
  "limit": 1,
  "count": 20,
  "mode": "timed",
  "durationSeconds": 60
}
```

`grade` 与 `ruleId` 必须匹配。`operation` 与 `limit` 为从规则表派生的兼容字段，保留供已有调用方过渡；其中 `limit` 仅为范围摘要，不能表示完整的乘除／分数规则。调用方不得继续将所有操作数统一限制为0到limit。校验会拒绝与规则不一致的兼容字段。

URL读取时将数字字段转为数值，再进行校验。旧的仅有operation、limit=20、count、mode和durationSeconds的加减法链接仍解析为一年级。显示标签从规则表获得，不信任URL传入的名称。

普通模式中的durationSeconds保留上次选择，供切回限时模式使用；它不表示普通练习启用了计时。

## 与其他模块的联调

后续答题模块需读取ruleId并实现真实题目、答案格式和判题；不能把新增设置入口当作对应功能已实现。小数输入需支持小数点，建议用十分之一整数计算以避免浮点显示误差；分数输入需支持分子和分母，接受等值答案及0／1，不强制儿童约分。整数混合运算用明确规则或运算树计算，不依赖字符串eval。

历史与错题后续需要保存规则版本、原题与精确答案形式；生成层写入规则版本，当前设置 URL 不必新增该字段。普通／限时／比赛共用规则目录，未实现的规则保持预览。表内乘法按交换乘数视为重复时只有 45 个算式，50 题请求需提示题库不足，不能无限重试。交接分工见扩展确认记录。
