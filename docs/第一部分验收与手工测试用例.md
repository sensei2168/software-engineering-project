## T27、T29、T30逐步操作说明

### T27 手机键盘与滚动 必测

1. 用Redmi K90打开限时练习，选择三年级整数口算，让页面内容足够长。
2. 点击题量输入框，确认数字键盘出现。
3. 删除原来的30，输入20；能正常定位、删除和输入即可。
4. 用键盘完成键或手机返回操作收起键盘。
5. 向上滑动页面，找到底部“确认设置，查看下一页”，点击进入摘要。
6. 确认下一页显示20道及原来选择的其他参数。

通过标准：输入顺畅，键盘能收起，页面能滚动到底部，按钮能点中并完成跳转。键盘弹出时按钮暂时在屏幕之外，并不自动算失败；重点是收起键盘后可以正常完成操作。结果仍待本人实际补测。

### T29 小屏与长文案 扩展检查

这项是在电脑的微信开发者工具模拟器中做，不要求Redmi K90变成小屏手机。

1. 找到模拟器的机型／尺寸选择，选较小屏幕的机型；如果支持自定义，设为约320px的页面宽度。
2. 打开三年级整数口算，观察四个双列按钮和整行混合运算。
3. 切到小数与分数，观察范围说明、勾选和分数示例。
4. 滚动到页面底部，点击确认。

通过标准：只有正常的纵向滚动，没有按钮重叠、横向溢出或文字遮挡。它测试的是布局在窄屏上的表现，不等于用模拟器验证了另一台真实手机。结果仍待执行；现有12项布局回归可作为补充证据。

### T30 非法链接拦截 扩展检查

这项检查的是：不能靠修改跳转参数，把一年级与三年级题型拼成一个错误的有效配置。

可直接引用已有自动测试中的“invalid grade/rule pairs and altered compatibility fields are rejected”作为自动验证证据；人工验证仍记未执行，不写成真机通过。

如希望亲自操作：在开发者工具添加一个自定义编译模式，启动页面填：

    pages/practice/practice

启动参数填：

    grade=1&ruleId=g3_fraction_same_den&count=20&mode=timed&durationSeconds=60

点击编译，预期显示“练习设置无效，请返回设置页面重新选择。”，不展示有效成绩或练习配置。完成后切回普通编译模式，避免以后每次都进入这个故意构造的错误场景。它不是需要另行开发的功能，也不是要求在手机上编辑网址。
