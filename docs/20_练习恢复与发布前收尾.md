# 练习恢复与发布前收尾

日期：2026-11-04。本页更新此前AC07“尚未实现”的状态；代码与自动验证已完成，组长反馈两种恢复测试通过。

## 已交付的恢复行为

普通和限时练习均保存最近一份未完成练习。原题、规则版本、原开始时间、答案及交卷中状态保存到本机，不重新出题。首页“单人练习”卡片出现“继续上次练习”；点击进入原练习。开始新练习前确认清除旧进度，其他入口不能静默覆盖未完成练习。

限时退出后继续计时，恢复时使用原截止；到时则锁定并交卷。交卷中断后恢复重试同一练习，记录按原编号去重。只有结果成功保存后才清除未完成进度；本机写入失败在页面提示，读取损坏保留原数据，不当成新练习。后台返回与保存失败仍遵循既有重试路径。

仅支持同一微信本机存储，清理微信数据、换设备不能恢复。当前是本地单人练习，不提供对恶意修改设备时间或存储的比赛防作弊保证；双人比赛仍由云端裁判。未完成快照包含本地判题所需原题数据，不上传云端。

## 验证

346项自动测试通过，包括5项新增专项：重启恢复同题同答案及原截止、超时恢复只结算一次、分数半填恢复、存储失败和损坏保留、交卷中断恢复、阻止新配置覆盖未完成练习（部分场景合并在同一测试）。首页／设置／答题WXML原生编译和房间契约检查通过。

这些为受控存储、清空会话内存和页面重建测试，不能替代微信实际杀进程验证。

人工反馈：袁嘉亮确认“两种恢复测试通过”，对应截止前恢复原题／答案／原计时，以及超过原截止后自动交卷且历史只有一条。此前同时提供了开发者工具重新编译和手机关闭微信两种操作说明，本次回复未注明采用哪一种，因此记录为人工恢复测试通过，不额外推断手机操作系统、机型或真实杀进程方式。

## 组长真机步骤

1. 重新编译，进入单人限时60秒练习，填前两题，记下题目和答案。
2. 真正关闭小程序并从最近使用中移除，过约10秒再打开。
3. 首页点击“继续上次练习”：同题、同答案、剩余时间减少，不能重置为60秒。
4. 再关闭，等超过原截止后重开并继续：应自动交卷，历史仅新增一条。
5. 普通练习填一题后重开：仍可继续，没有限时；选择开始新练习会先询问是否清除未完成进度。
