## 1. 当前能做什么

| 运行方式 | 已接入 | 边界 |
| --- | --- | --- |
| 默认真实基础房间 | 创建、六位码加入、查询、本人准备／取消准备、退出确认、房主关闭；统一客户端恢复未确认操作 | 复用已部署P2接口。本轮自动测试使用内存服务端模型，未重新执行真实云端／双账号验证 |

## 2. 在开发者工具中打开

项目目录为本仓库内的miniapp，即本机D:/ruangong work/software-engineering-project/miniapp。前端不需要构建npm或新增云环境。

1. 确认当前代码为feat/room-pages，然后在微信开发者工具重新编译。
2. 从原首页的“双人答题／查看比赛页面”入口打开房间页；默认是真实基础房间入口。
3. 开发版和体验版可点击“进入模拟演示”。顶部会持续显示“模拟演示 · 全部房间和成员均为演示数据”。
4. 也可设置自定义编译：启动页面pages/room/room，参数mode=demo；这不会绕过版本限制，正式版会忽略该参数。

GitHub权限不等于小程序开发／体验权限。真实模式使用项目AppID和config/cloud.js中的共同环境；遇到身份或环境错误按[部署指南](09_云开发部署与双账号验证.md)处理，不重新开通或部署资源。

## 3. 一次模拟演示

1. 进入模拟演示，点击“修改比赛设置”。选择年级、题型、题量和时长；摘要随选择更新。确认后创建房间，显示我为房主、1/2人。
2. 在下方“演示控制”点击“伙伴加入”，显示2/2人和双方未准备。
3. 点击“我准备好了”，再用演示控制“切换伙伴准备”模拟另一人准备。双方就绪本身不自动开始。
4. 房主点击“开始比赛”，回到页面顶部显示3秒倒计时；加入者视角只显示等待房主开始。
5. 开赛前点击“取消开始”，保留原房间与两人，双方重新准备。重新开始会产生新批次和新的起止时间。
6. 倒计时结束仅显示“演示已开赛”的答题页接入位置；可点“结束本次模拟演示”，确认后重新测试，不必等整局结束。

“切换房主／加入者”只改变演示视角，不改变成员和准备。演示控制按钮不属于正式比赛操作。结束演示只清除本机模拟房间，不影响真实环境。

## 4. 断线恢复复查

准备或倒计时阶段用“模拟连接失败”；倒计时页另有“模拟断线（演示）”，方便在3秒窗口内点击。

- 准备后断线再重试：仍为两人，我和伙伴各自的准备状态保持原样。
- 倒计时内重连：沿用原startAt，显示剩余时间，不重新倒数3秒。
- 断线期间已开赛：重连显示答题接入位置；原截止时间到达后显示结束接入位置，不伪造分数。
- 断线期间明确模拟伙伴准备变化、服务端取消开始或关闭房间：重试显示更新后的快照，并提示明确的模拟服务端事件。
- 取消开始清除准备和旧批次；开赛后模拟服务端拒绝开赛前的取消／关闭行为。

网络中断不会清空成员、暂停时间或延长等待期限。旧的未确认写操作必须先重试；不能连续点击新建。尚有活动房间时先恢复、再确认退出，不能靠返回入口遗弃未确认操作。

## 5. 真实基础房间联调

1. 退出活动的模拟房间或结束模拟演示，再切换真实房间；真实与模拟数据分开保存。
2. 两名获准测试者连接同一环境：甲创建，乙输入真实房间码加入。不要把演示房间码当作真实房间。
3. 每次操作后页面采用云端返回的快照；另一端点“刷新房间状态”查看变化。页面返回前台也会查询当前房间。
4. 准备和退出携带最新版本。若发生VERSION_CONFLICT，页面先刷新并要求再次确认，不会自动覆盖伙伴的新状态。
5. 写请求丢响应时显示“重试未确认操作”，调用已有room-client.retryPending，保留原编号和原参数。关闭再进入仍可恢复确认。
6. 房主退出需确认；加入者退出释放席位；房主关闭、等待失效、非成员访问和网络失败分别显示对应提示。

联网开始／取消按钮目前不开放。自动轮询、正式校时和比赛批次同步仍与彭方鑫的后续适配对齐，本轮没有另写一套云端轮询器；仅本机倒计显示使用定时器，离开前台或卸载会清除。

## 9. 2026-11-02反馈与计时复核

原始反馈（整理换行，未改变含义）：

> RP12：在倒计时三秒内模拟断联后进行重连，发现比赛倒计时不是从设定好的时间（如120s）开始计时的，如果等了一会儿再重连，那这段时间也在进行着倒计时。

> RP14：3秒倒计时和比赛的时间会持续进行，不会因为切页面而终止。

依据docs/07第4节：准备3秒不占比赛时长；已开赛后不暂停，断线和切后台不改变startAt／endAt。两项现象已在本地页面模型中复现，当前没有发现额外扣时。现有描述不足以认定为计时缺陷，不能未经团队变更规则而改为暂停。页面现增加明确说明，仍待用户核对具体秒数。

以房主点击开始为第0秒、比赛时长120秒为例：

| 返回时间 | 应显示 |
| --- | --- |
| 第1秒重连或回前台 | 仍在开赛准备，剩2秒 |
| 第3秒到达开赛瞬间 | 比赛剩120秒，前3秒没有扣入比赛 |
| 第7秒重连或回前台 | 比赛已经进行了4秒，应剩116秒 |
| 第123秒或之后返回 | 已结束，不重新发120秒 |

如果第3秒刚开赛就明显少于120秒，或短时间重连使原截止时间改变，请另记所选时长、断线前后秒数和截图；那属于需要继续排查的偏差。新增自动用例验证原起止时间保持不变；这些是本地复查，不替代用户真机确认。
