# 房间开赛出题适配

`miniapp/cloudfunctions/roomService/question-generator.js` 与 `question-strategies.js` 来源于何顺 PR #5 的提交 `0d98d88d8841abbbd2d193dbe59a4b0fc62d6940`（原路径 `miniapp/utils/question/` 中的 generator.js、rule-strategies.js）。本轮仅复用出题纯函数，不合入该 PR 的页面、判分、结果交接或未完成云函数。

本地修正：单步整数加法按交换操作数去重，小题库只保留 a≤b，大题库用排序键；修正加法容量估算。版本记为 `1.3.0-room.1`。小数输入四舍五入判分缺陷位于未复用的 `scoring.js`，本目录不承担判分。

`question-set.js` 使用服务端随机种子生成一套真实题目，将题号改为批次内的 `q_1`…`q_N`，规则版本取 `rules.generated.json`。私有原题含精确答案和结构化运算参数，保存在服务端房间文档的 `attempt.questions` 中，供后续裁判使用。输出仅允许 id/index/ruleId/text/answerKind；未到 startAt 不返回任何题目。

后续何顺修订数学模块时，由组长审核差异后统一版本并同步此目录，不自动从未审查的分支复制。现有已开始批次保留生成时的题目和版本，不因代码升级重算。后续裁判必须按 roomId + attemptId 读取该原题，不能相信客户端题目、答案或分数。
