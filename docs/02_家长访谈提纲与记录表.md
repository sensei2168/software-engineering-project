# 家长访谈提纲与记录表

状态：尚未开展访谈。以下是问题与空白记录模板，不是访谈结果。

## 1. 访谈安排

- 对象：小学一至三年级学生的家长，优先选择最近有口算练习经历的人。
- 时长：每位约 10—15 分钟；先约 2—3 位做探索，不将少量样本结论推广到所有家庭。
- 方式：电话、文字或当面均可。由组员联系真实对象；AI 可以辅助整理，但不能代替家长回答。
- 记录：用 P01、P02 等匿名编号，记年级及具体做法即可，不必收集孩子姓名、学校或联系方式。
- 方法：先问最近的具体经历，再问困难，最后介绍候选方案。避免开场直接问“您是不是很需要自动出题”。

## 2. 可直接使用的开场白

您好，我们正在做软件工程课程项目，想了解小学家庭的口算练习情况，大约需要 10—15 分钟。我们目前还没确定全部功能，想先听听您最近一次的真实经历。没有标准答案，不需要提供孩子姓名。我们会匿名整理您的回答用于课程需求分析，您可以跳过不想回答的问题。您是否愿意参与并允许我们做文字记录？

如对方不同意，结束访谈；如希望录音，另外征得同意，不默认录音。

## 3. 核心问题

| 编号 | 提问 | 可选追问 | 用途 |
|---|---|---|---|
| Q01 | 孩子现在几年级？最近一周是否做过口算练习？ | 大致做了几次，每次多少题？没有做也可以如实说明。 | 核实对象、频率及题量；不预设人人每天 30 题 |
| Q02 | 请按顺序讲讲最近一次练习，从拿到题目到完成订正是怎样进行的。 | 题目由老师、练习册、您还是其他工具提供？谁参与了哪些步骤？ | 找到实际流程；确认家长是否真的需要出题 |
| Q03 | 那一次您分别花了多少时间准备题目和批改？最费事的是哪一步？ | 是估计还是有记录？可以举一个具体困难吗？ | 区分主要问题与可量化基线 |
| Q04 | 目前做哪些题型？您怎么判断题目适不适合孩子？ | 最近题目的数值范围、进退位、乘除、余数等是什么情况？能否提供不含个人信息的例题？ | 决定规则；家长例题不等于已验证课程标准 |
| Q05 | 孩子目前在哪里、用什么方式答题？您希望继续保持哪些做法？ | 是纸笔、手机还是口头？哪些情况下不适合用手机？若用手机出题，答案仍写在纸上是否更合适？ | 决定在线作答或纸笔流程，避免选错核心方案 |
| Q06 | 您现在什么时候、怎样批改和订正？ | 希望每题后反馈还是全部做完后反馈？漏题如何处理？看标准答案是否会影响练习？ | 确定反馈时机、结果及异常处理 |
| Q07 | 做错的题后续怎么处理？哪些记录真正会再看？ | 重做原题还是练同类题？多久再练？需要保留多少天？ | 核实错题与历史记录的价值 |
| Q08 | 通常是谁的设备用于练习？谁会查看结果？ | 是否需要换手机继续、两个家长分别查看，或给多个孩子使用？ | 决定同步和档案需求 |
| Q09 | 您用过哪些口算练习办法或工具？为什么继续使用或放弃？ | 请讲一个方便之处和一个具体问题；如果当前办法已足够，也请说明。 | 调查替代方案，避免假设已有工具都不好 |
| Q10 | 如果只能先解决一个问题，您会选什么？ | 在了解以上经历后，再介绍候选的按范围出题、自动批改、错题重练，请其排序并说理由；也可提出其他需求。您愿意之后试用吗，什么情况会让您放弃使用？ | 确定优先级与后续验证方式 |

如时间不足，优先问 Q02、Q03、Q04、Q05、Q06、Q10。记录估计值时标注“受访者估计”，不要加工成计时实测。

## 4. 访谈结束时的复述确认

“我理解您现在的做法是……，主要困难是……，最希望先解决的是……，其中……暂时不需要。我的理解准确吗？有没有遗漏？”

把对方的修正一并记录；只有实际完成这一步，才能标注“受访者已确认理解”。

整理规则：保留原意；区分“家长说了什么”和“团队推断什么”；不同家长意见冲突时记录差异并回访，不强行写成一致。题型规则可另请教师或结合教材核对。访谈只能支持需求判断，不能证明软件性能、正确率或学习效果。

## 7. 暂时联系不到家长时

先做组内场景讨论和纸面原型，把问题、假设和待核实项留下来；通过亲友等渠道寻找自愿参与者。如果使用 AI 模拟家长，只能标为“模拟演练”，不得计入真实访谈人数、家长意见或人工核实结果。
