## 项目简介

本项目采用课程参考选题二“儿童学习”，拟服务于小学一至三年级学生及家长，通过微信小程序帮助家庭完成口算出题、练习与批改。课程情境中的“每天 30 道题”作为默认题量的设计依据，不代表已调查到的家庭习惯。

首版候选流程：家长设置题型与范围 → 生成练习 → 孩子作答 → 自动批改 → 订正与查看记录。先打通加减法流程，再补齐整数乘法、整除及复习功能。当前提案使用本设备记录，暂不做拍照识别、班级管理、云同步和纸质导出。

目前没有家长访谈渠道，本阶段不安排家长访谈，改以课程与教材资料、同类工具分析、教师审阅和原型试用细化需求。真实家庭的手机／纸笔偏好仍未验证；同学试用不能替代家长和儿童的使用验证。
