## 项目简介

本项目采用课程参考选题二“儿童学习”，拟服务于小学一至三年级学生及家长，通过微信小程序帮助家庭完成口算出题、练习与批改。课程情境中的“每天 30 道题”作为默认题量的设计依据，不代表已调查到的家庭习惯。

单人流程：家长设置题型、范围、题量及是否限时 → 生成练习 → 孩子作答 → 提交或到时自动批改 → 订正与查看记录。保留不限时模式，先实现加减法及限时，再补齐乘法、整除和复习功能。

新增双人在线比赛：一方创建房间，另一方输入房间码加入，双方准备后答同一套题；服务端统一计时和判分，比赛结束后显示双方成绩及结果。房间码、时长、计分与平局是细化提案，见[教师反馈与需求变更记录](docs/06_教师反馈与需求变更记录.md)。

单人记录继续在本机保存，比赛增加后端、可信身份和云端房间状态。候选方案为微信云开发，环境、权限和费用待验证；暂不做个人历史跨设备同步、随机匹配、多人比赛、聊天、公开排行榜、拍照识别、班级管理和纸质导出。

目前没有家长访谈渠道，本阶段不安排家长访谈，改以课程与教材资料、同类工具分析、教师审阅和原型试用细化需求。真实家庭的手机／纸笔偏好仍未验证；同学试用不能替代家长和儿童的使用验证。
