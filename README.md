# 小学口算练习微信小程序

> 小组项目立项草稿 v0.2｜更新日期：2026-10-09。已确定选题、产品载体与 GitHub 仓库，尚未开展家长访谈，未开始正式开发或发布。

项目仓库：[sensei2168/software-engineering-project](https://github.com/sensei2168/software-engineering-project)。

## 项目简介

本项目采用课程参考选题二“儿童学习”，拟服务于小学一至三年级学生及家长，通过微信小程序帮助家庭完成口算出题、练习与批改。课程情境中的“每天 30 道题”作为默认题量的设计依据，实际家庭的题量和练习方式仍需访谈确认。

首版候选流程：家长设置题型与范围 → 生成练习 → 孩子作答 → 自动批改 → 查看错题和练习记录。是否需要纸笔练习、打印及跨设备查看，尚未确定。
